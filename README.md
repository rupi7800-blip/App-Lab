# App Lab

Sito vetrina di **App Lab – Laboratorio di applicazioni web su misura** per liberi professionisti, ditte individuali e PMI.

Sito statico (HTML + CSS + un po' di JS), nessuna build necessaria: apri `index.html` o servi la cartella con qualsiasi web server.

## Da completare prima della pubblicazione
- Sostituire l'email `info@example.com` (in `contatti.html`)
- Completare `privacy.html` con i dati del titolare
- Aggiungere logo definitivo, progetti reali e testimonianze quando disponibili
